# Мапи команд

Після оновлення сторінки світу натисніть **M / ь** (фізична клавіша M).
Переглядач займає всю область Foundry. Бібліотека схована за кнопкою у верхньому лівому кутку.
Якщо мапи немає, налаштування відкриваються одразу: виберіть або створіть команду й завантажте мапу.
Кнопка «Завантажити» приймає PNG, JPEG та WebP до **10 МБ (10 485 760 байтів)** включно.
Перевірка розміру й декодування відбуваються до відправлення файлу.

Вибір мапи у верхньому списку спільний для команди. Вікно не відкривається в інших
учасників примусово. Колесо змінює масштаб, перетягування пересуває мапу,
подвійний клік відновлює початковий вигляд. Повторне M або хрестик закриває вікно.
Esc спочатку ховає меню, наступний Esc закриває переглядач.
Після вибору мапи бібліотека ховається. Нова завантажена мапа стає активною.
У полях введення хоткей не перехоплюється. Перепризначення: налаштування клавіш Foundry.

⚙ у меню відкриває вибір/створення команди та керування бібліотекою. Прибрати мапу з
бібліотеки може її завантажувач або GM; оригінальний файл залишається в assets.
Альтернативний вхід: налаштування модуля → «Мапи команд», або API:
`game.modules.get('fantik-automations').api.partyMaps.open()`.

Адміністратор один раз створює `<Foundry User Data>/Data/assets/party-maps`
на сервері й надає користувачу ОС, під яким працює Foundry, право запису в цю теку.
У Docker це має бути каталог у змонтованому сховищі даних Foundry.
Модуль не створює тек і не потребує серверної адміністративної сесії.
Для завантаження GM має надати ролі гравця дозвіл **Upload Files**;
**Browse Files** цьому завантажувачу не потрібен. Модуль не змінює дозволи.
Створення команд, вступ і перегляд не потребують права завантаження або онлайн-GM.

Усі нові файли зберігаються в `assets/party-maps/` з унікальними іменами,
які включають світ, ID команди та ID мапи. Бібліотеки розділяються за ID команди.
Наявні мапи залишаються за старими шляхами; переміщувати їх не потрібно.
Навіть для старих команд нові завантаження використовують спільну теку.

Членство, створені команди, внески в бібліотеку й вибір мапи зберігаються у flags
документів User цього світу. Зміни передаються штатною синхронізацією Foundry;
кожен гравець змінює лише свій документ. При переході до іншої команди внески
залишаються у попередній. Не видаляйте користувача-засновника/завантажувача, якщо
потрібно зберегти його записи каталогу: перед видаленням потрібне перенесення flags.
У резервну копію включайте світ і assets. Команди відкриті для самостійного вступу;
фільтрація бібліотеки не є захистом секретних файлів.

Ліміт 10 МБ стосується цього завантажувача; він не змінює серверні ліміти Foundry
або reverse proxy. Файли, додані в теку вручну, автоматично не індексуються.
