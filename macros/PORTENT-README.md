# Portent — два кубики

Самостійний Script macro для Foundry v14. Для 3D-анімації потрібен увімкнений Dice So Nice; без нього значення все одно зберігаються.

## Встановлення

Створи макрос і через його контекстне меню **Import Data / Імпорт даних** імпортуй `Portent-macro.json`.

Або створи макрос типу **Script**, встав весь вміст `portent.js` у Command і збережи.

## Використання

Просто запусти макрос. Він завжди використовує персонажа, прив’язаного до поточного користувача (`game.user.character`). Токен на сцені та його виділення не потрібні; вибрані токени не впливають на вибір персонажа. Якщо персонажа не прив’язано, макрос підкаже обрати його в налаштуваннях користувача.

- Спочатку показуються два порожні кубики.
- **Заповнити пусті** кидає d20 лише для порожніх комірок.
- **Переролити всі** заново кидає обидва d20 й замінює всі попередні значення, навіть якщо комірки заповнені. Використовуй після довгого відпочинку; кнопка запускається вручну, без автоматичної прив’язки до відпочинку. Після Dice So Nice нові значення публікуються в одній картці. Введена фраза зберігається.
- Клік по одному порожньому кубику заповнює лише його.
- При заповненні в загальному чаті з’являється одна картка **«Майбутнє проясняється»** з результатами нових кубиків: одним числом або двома окремими числами. Картка з’являється після завершення 3D-анімації та не використовує й не змінює текст у полі **Твоя фраза**. Якщо Dice So Nice недоступний, картка публікується одразу.
- При заповненні Dice So Nice показує темно-фіолетові металеві d20 з мармуровою текстурою та золотими цифрами. Анімація синхронізується з іншими підключеними гравцями й показує саме збережені результати. Особисті налаштування дизайну інших кидків не змінюються.
- Клік по заповненому кубику публікує його значення в красивій фіолетово-золотій картці в загальному чаті й звільняє комірку.
- При відкритті вікна випадково обирається одна з 11 фраз. Поле **Твоя фраза** можна переписати перед використанням кубика; саме його текст потрапляє в чат. Після успішної публікації обирається нова фраза. Заповнення порожніх кубиків зберігає введений текст. Порожнє поле прибирає фразу з картки.
- Набір фраз можна змінити в масиві `PHRASES` на початку коду макроса.
- Вікно залишається відкритим. Повторний запуск піднімає вже відкрите вікно.
- Значення зберігаються на персонажі між сесіями (`flags.world.fantikPortentDice`).

Макрос не змінює чужі кидки й не витрачає дію/реакцію. Заповнені комірки перекидаються лише кнопкою **Переролити всі**.

Не використовуйте одночасно той самий набір кубиків із двох клієнтів. У межах одного клієнта є захист від подвійних натискань.
