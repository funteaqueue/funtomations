# Chromatic Orb · Стандартний пікер застосування

Foundry VTT 14 / dnd5e 6. Для інтеграції стандартного пікера у стилізовану картку використовується вже наявний Fantik Automations 0.5.0 / API 4 або новіший. Оновлення модуля до 0.6.x не потрібне. Спеціальні кнопки шкоди/зцілення та GM-підказки влучання не використовуються.

## Встановлення

Повторно імпортуй `chromatic-orb-chain.json` через Import Data у меню макросу або встав увесь `chromatic-orb-chain.js` у Script-макрос. Обидва файли містять однаковий код. Макрос не імпортовано у світ автоматично; бази даних світу не змінено.

## Робота

1. Виділи токен заклинача. Без виділення використовується призначений персонаж; із кількох виділених можна вибрати одного. Перше джерело заклять обирається автоматично. Остання обрана стихія зберігається у прапорці користувача поточного світу та відновлюється при наступному запуску, також після перезавантаження. Вибір запам’ятовується одразу, навіть якщо потім скасувати каст; за відсутності збереженого вибору використовується блискавка.
2. Вибери рівень або «Магія пакту» у списку чарунок. Поруч доступні списання чарунки та ігнорування відстані. Режим атаки задається горизонтальним перемикачем перед вибором відповідної цілі.
3. Обери чергу цілей на сцені. Нумерація й маршрут показують порядок; коло — радіус. На час вибору цілей курсор миші над сценою замінюється прицілом кольору стихії; над недоступною або вже обраною ціллю він червоний. Центр прицілу є точкою кліку. Після вибору або закриття повертається звичайний курсор. Остання дозволена ціль запускає перший кидок. Неповну чергу можна запустити кнопкою «Почати кидки». ↶ / Backspace скасовує останній вибір до початку.
4. Після результату підтвердь «Влучання · стрибок» або заверши ланцюжок. Без дубля, при натуральній 1 або наприкінці черги панель автоматично закривається. При сліпому кидку, прихованому від гравця, рішення залишається за GM, щоб поведінка панелі не розкривала результат.
5. Уся історія дописується в одну картку. Значок d20 показує атаку, d8 — суму поточного ефекту. При наведенні на підсумкові числа показано формулу зі значеннями кубиків і сумою: наприклад, 1d20(5 | 14) + 2 + 5 = 21, де відкинутий 5 перекреслено; для шкоди — 3d8(2 | 3 | 4) = 9; окремі рядки кубиків і формули прибрано. Позначка дубля залишається.

## Застосування

GM використовує звичайний системний пікер Apply. Для зцілення можна вручну задати множник −1. Макрос не змінює HP автоматично й не містить власних кнопок застосування.

Після перескоку пікер отримує лише шкоду нового кроку й записану ціль. **Застосуй поточний результат перед наступним перескоком.** Попередні результати залишаються в картці для перегляду; пікер не складає їх із поточним. За потреби попередній результат можна внести вручну. Повторне натискання Apply регулюється стандартною поведінкою системи, без додаткового блокування макросом.

Технічно `ChatMessage.rolls` містить лише поточний DamageRoll, оскільки системний пікер агрегує ці кидки. Повна історія оцінених атак і шкоди зберігається у `flags.world.fantikChromaticOrb.history` та відображається через інтерактивні посилання в тій самій картці. Режим приватності чату зберігається. Нових прихованих перевірок КБ немає.

Без Fantik Automations доступна звичайна картка з усіма кидками й ручне застосування; вбудований пікер у стилізованій картці потребує наявної інтеграції API 4. «Без цілі» очищає заплановані цілі й кидає без прив’язки до істоти. «Лише картка в чат» не виконує кидків. Відсутність сцени, персонажа або чарунок не блокує ручний режим. Ресурс списується один раз; скасування до початку нічого не витрачає.

## Візуальні ефекти

Сфера в картці залишається різнокольоровою хроматичною. JB2A-переліт і пульсація забарвлюються за стихією: кислота — лаймова, холод — крижано-блакитна, вогонь — помаранчевий, блискавка — фіолетова, отрута — зелена, грім — бузковий. Використовується нейтральний варіант тих самих Energy Strands із Sequencer tint; якщо його немає — відповідний кольоровий варіант. Коло дальності також зберігає колір стихії.

Sequencer і встановлені JB2A дають переліт та пульсацію біля поточної цілі. Без цих модулів кидки працюють зі схемою маршруту. Публічні ефекти транслюються, приватні залишаються локальними. Звуку немає. Ефекти очищаються при завершенні, скасуванні та зміні сцени; reduced motion вимикає анімацію. JB2A-медіа не входять до файлів макросу.

## Перевірка

Пройдено 18 браузерних сценаріїв з моделями Foundry/DSN/Sequencer й API 4, перевірку синтаксису, реальний HTML-санітайзер Foundry 14 та відповідність JS/JSON. Перевірено передачу лише поточної шкоди системному пікеру, зміну цілі, збереження всіх кубиків і оригінального DOM-елемента пікера. Живий каст та натискання Apply у світі Foundry не виконувалися.
