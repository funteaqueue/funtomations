# Навичка створення макросів для ДнД-чату

Надішліть `foundry-macros-community.zip` цілком: один SKILL.md без references/assets не містить прикладів і довідки API.

Для Codex: розпакуйте папку `foundry-macros` у `~/.codex/skills/` (Windows: `%USERPROFILE%/.codex/skills/`). Потім попросіть: «Використай $foundry-macros для створення макроса …».
Для іншого AI-інструмента: прикріпіть доступні йому SKILL.md, потрібні references та приклад макроса; підтримка автоматичного завантаження навичок залежить від інструмента.

## Текст для чату

Ділюся навичкою для створення макросів під Foundry VTT 14 / dnd5e 6.x. Усередині — правила компактного українського інтерфейсу, приклад Chromatic Orb, кидки з Dice So Nice, вибір цілей і довідка кастомних функцій нашого модуля.

Модуль: https://github.com/funteaqueue/fantik-automations

Приклад запиту: «Використай foundry-macros. Створи макрос для [назва/механіка]. Потрібні .js і JSON для імпорту. Використай компактний інтерфейс Chromatic Orb та доступні функції Fantik’s Automations; збережи ручний режим без модуля».

Модуль опційний: додає картки з GM-контролями, перевірки збережених цілей та інші можливості. Навичка — інструкції для AI, а не встановлений макрос чи гарантія коректності будь-якого згенерованого коду. Готовий макрос спочатку перевіряйте на тестовому токені.
