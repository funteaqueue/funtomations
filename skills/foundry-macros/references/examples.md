# Приклади для авторів макросів

## Основний зразок: Chromatic Orb v3.1

[assets/chromatic-orb.js](../assets/chromatic-orb.js) — оновлений користувачем зразок зі спільною лінією черги цілей і покроковими кидками в одній картці: компактний вибір цілей, курсор, підказки з усіма кубиками, один ланцюжок результатів, ручне застосування. Читайте [ui-design.md](ui-design.md) перед адаптацією. Це приклад конкретного закляття, не універсальний рушій правил. API 4, який він використовує, збережено в API 5.

JSON поруч із JS можна імпортувати у Script Macro через Import Data. Він містить той самий код. Приклад має перевірки з моками та браузерні прев’ю; перевірка у вашому світі й з вашими модулями все одно потрібна.

## Інші приклади в репозиторії

[Каталог macros](https://github.com/funteaqueue/fantik-automations/tree/main/macros):

- **Chromatic Orb chain** — актуальний приклад ланцюжка атак; перед використанням прочитайте його README про застосування шкоди до наступного стрибка.
- **Portent** — приклад компактної панелі зі збереженням кубиків і Dice So Nice. Вибирає призначеного персонажа, а не виділений токен; це спеціалізований приклад стану, не шаблон вибору заклинача.
- **Toll the Dead** — приклад залежного від стану цілі кубика. Для нових макросів використовуйте generic spellCards API і ручний вибір стану, якщо GM-перевірка недоступна; не копіюйте старі spell-specific flags.
- **Serpent Tongue** — спеціалізована інтеграція з модулем і налаштованими activities. Не підходить як самостійний універсальний шаблон.

[assets/eldritch-blast.js](../assets/eldritch-blast.js) — історичний технічний приклад. Його обмеження описано в [eldritch-example.md](eldritch-example.md); не копіюйте старий вибір заклинача й цикл Dice So Nice без адаптації.

Цей пакет не переписує механіку перелічених макросів і не оголошує їх усі еталонними. Для нового макроса пріоритет мають поточні вимоги SKILL.md.
